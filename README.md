# Real-time-Chat-App
A simple real-time chat app using React and Tailwind for front end with node.js, socket.io for back end and mongoDB for the database.

## Deployment
This project's frontend is deployed in vercel while the backend is deployed in Render.  
You can check the website [HERE](https://real-time-chat-app-e6iq-liard.vercel.app/).
